## シミュレータ環境の制限（重要）

Windows Icarus Verilog 14.0(devel)は、今回22本すべてでコード生成の `DONE.` 後に
アクセス違反 `3221225477` で終了しました。コンパイラ正常終了は **0/22** です。
各回新しいファイル名で生成されたVVPを確認し、診断オプションを明示した場合だけ
実行しています。そのVVPの実行終了コードは全22本0で、全アサーションがPASSです。
これは「コンパイルから実行まで全過程が正常終了」という報告ではありません。

`run_sim_tests.py` は標準では非0コンパイラ終了を拒否します。
`--diagnostic-compiler` だけが、この既知コード＋DONE＋新規生成物の条件を満たす
ケースを診断用に許可します。VPIパスの正規化はパス行だけに限定し、Verilogの
文字列エスケープを変更しないようにしています。

移動先の登録ソースはVivado `xvlog` で解析成功しました。しかし `xelab` は
生成Cファイル `xsim_2.c` のコンパイルで `XSIM 43-3409 / 43-3915` となりました。
従って **XSimでのシミュレーション完走は未確認** です。原因はこの環境では
解決しておらず、ユーザー環境でも必ず起動すると保証するものではありません。
XPRを開いて合成・bit生成する経路と、XSimの起動経路を区別してください。
解析/エラーログは `reports/relocation/` に保存します。

## 配置配線後の資源・タイミング

対象 `xc7a35tcpg236-1`、基板100MHz入力→MMCMで内部25MHz。CPU、周辺回路、
画素回路は同じ25MHzドメインです。VGAは25MHz/(800×525)≒59.524Hzです。

| 項目 | 使用量/結果 | デバイス容量 |
|---|---:|---:|
| Slice LUTs | 5241 (25.20%) | 20800 |
| LUT as Memory | 44 | 9600（上記LUT数の内数） |
| Slice Registers | 4295 (10.32%) | 41600 |
| RAMB36 | 5 (10.00%) | 50 |
| DSP | 0 | 90 |
| WNS | +8.576ns | — |
| TNS | 0ns | — |
| WHS | +0.025ns | — |
| THS | 0ns | — |
| DRC違反 | 0 | — |

内部未制約終点は0。非同期スイッチ・ボタン・PS/2の10入力は同期器までの
例外があり、外部同期クロックに対する入力遅延を与えていません。ゲームやCPUの
クリティカルパスをfalse pathにしてタイミングを通したものではありません。

`report_methodology` は6件のWarningが残ります。内訳は既存reset構成に対する
LUTAR-1が1件、BRAM出力レジスタ未統合のSYNTH-6が2件、XDC検索効率の
XDCB-5が3件です。DRC 0を「すべての警告が0」と読み替えないでください。
resetは非同期アサート・同期解除を用いますが、元のreset信号合成経路について
この警告が残ることを明示します。

電力レポートのTotal On-Chip=0.191Wはベクトルレス推定であり実測ではありません。
資源・タイミングの元rptとbitは `programming/`、元の全体実行ログも同フォルダです。
WNSから推算した周波数を保証Fmaxとはせず、本版の正式設定は25MHzとします。

## 初回実機確認の順番

1. ZIPを短い英数字パスへ展開、SW15=0、SW14=0でbitを書き込む。
2. SW0=0で開始し、従来のボタン・NEXT・落下・再開を確認する。
3. J2へUSBキーボードを直接接続し、SW0=1で開始する。
4. ←/→/↓/Z/Xの押下と解放、同時押し、長押し、再戦時保持を確認する。
5. 同一出現順、同時消去・連鎖、予告・相殺、30個持越し、結果表示を確認する。
6. LED15（CPU fault）が点灯しないことを確認する。

キーボードの無線受信器/複合デバイス相性、解放通知を失う抜差し、2ms受信
タイムアウト設定の妥当性、モニタの25MHz画素クロック受入れは実機で確認が必要です。
