# ２人対戦 VGA 表示

## 役割と既存表示の継承

`PuyoVersusVideo` は CPU が公開した表示情報を描画するだけの回路である。
衝突、消去、攻撃量、相殺、勝敗はここでは計算しない。従来の
`PuyoVideo.v` を変更せず内包し、１人用の `PLAY` 中はその RGB をそのまま
選択する。１人用のプレイ画面の配置・色・文字・ぷよ形状は維持する。
１人用の開始前・カウントダウン・終了後だけ、画面上端 24 pixel に
モード・開始/再戦案内の帯を追加する。したがって、開始前まで含めて
旧画面の全 pixel が一致するという意味ではない。

対戦は左右に２面を配置する。ぷよのマスは従来と同じ **32×32 pixel** で、
盤面自体を縮小していない。サイドバーの文字を 5×7 pixel（文字ピッチ 8）
にすることで二つの盤面と全情報を 640×480 に収めた。

## 画面配置

座標は可視領域の左上を `(0,0)` とする。

| 内容 | P1 | P2 |
|---|---|---|
| ６列×12行の盤面 | x=16..207, y=48..431 | x=336..527, y=48..431 |
| 盤面の外枠 | x=12..211, y=44..435 | x=332..531, y=44..435 |
| 状態・スコア・連鎖・予告 | x=216 から | x=536 から |
| NEXT 二個 | x=232..263, y=288..351 | x=552..583, y=288..351 |
| 操作説明 | x=16, y=440/456 | x=336, y=440/456 |

サイドバーは `PLAY/RESOLVING`、10桁の `SCORE`、3桁の `CHAIN`、
3桁の `LAST`、5桁の `INCOMING`、`NEXT` を示す。予告数は 0..65535 を
省略せず表示する。試合終了時は各側に `WIN` / `LOSE`、同時敗北は
両側に `DRAW` を表示する。画面上端には SW0 のモード、SW14 の開始・再戦、
`READY` と残り秒を表示する。

通常色は旧版と同じ RGB444 値（赤 F45、緑 4E6、青 49F、黄 FD4）。
おじゃまは色番号 5、灰色 AAA である。色番号と形状描画は分離してあり、
`palette` と `puyo_pixel` を差し替えることで将来の画像素材へ置換できる。
消去マークは白で強調し、目の形状は旧版を継承する。

内部盤面の y=0,1 は表示せず、画面の最上段は内部 y=2 に対応する。
操作中の二個は固定盤面とは別の座標・色で重ねて描画する。

## 入力の packed 形式

すべての二人分フィールドは **下位側が P1、上位側が P2** である。
これらは MMIO 公開レジスタからの表示用コピーであり、ゲーム状態の正本ではない。

| ポート | 全幅 | 一人分の内容 |
|---|---:|---|
| `boards` | 504 bit | 252 bit。セル `(y*6+x)` の色を `[index*3 +: 3]` に格納 |
| `clear_masks` | 168 bit | 84 bit。セルごとの消去表示マーク |
| `active_words` | 32 bit | 16 bit。x[3:0], y[7:4], 向き[9:8], 色A[12:10], 色B[15:13] |
| `next_pairs` | 12 bit | 6 bit。NEXT A[2:0], B[5:3] |
| `scores` | 64 bit | 32 bit unsigned |
| `status_words` | 56 bit | 28 bit。chain[7:0], last[15:8], phase[23:16], active[24], busy[25], over[26], boot[27] |
| `pending_counts` | 32 bit | 16 bit unsigned |
| `match_status` | 32 bit | 共通情報。mode[0], state[3:1], result[6:4], countdown[9:8] |

`mode` は 0=１人用、1=対戦。
`state` は MENU=0、COUNTDOWN=1、PLAY=2、RESULT=3。
`result` は未確定=0、P1勝利=1、P2勝利=2、DRAW=3、１人用終了=4。

## フレームの一貫性

CPU は二人分のステージング情報を順に MMIO へ書き、最後に一度 commit する。
MMIO 回路はそのクロックで二人分と試合情報をまとめて公開する。
さらに VGA は `(pixel_x,pixel_y)=(0,480)` の垂直帰線期間の開始で、公開値を
すべて同時にフレーム表示レジスタへ取り込む。次の可視フレームの途中では
取り込まない。これは **MMIO の一括公開 → VGA のフレーム取込み** の二段階で、
CPU 転送中の盤面や、異なる更新世代の P1/P2・勝敗表示が混ざることを防ぐ。
commit と VGA 取込みが同じクロックの場合、Verilog の非ブロッキング代入により
前の公開済み一式を取り込む。新しい一式は次のフレームで反映される。

１人用の旧描画回路と対戦描画回路のカウンタは同じ reset とクロックで進み、
同期信号の位相を一致させる。選択するモードもフレーム単位で保持するため、
試合中に信号の位相が切り替わる構成ではない。

スコアは 32 クロック、予告数は 16 クロックの double-dabble で十進 BCD に
変換する。処理は垂直帰線期間に行い、可視画面開始前に終わる。
32 bit の除算回路でスコアの各桁を毎 pixel 計算する構成は採用しない。

## VGA タイミング

pixel clock は 25 MHz。可視領域 640×480、全体 800×525、約 59.52 Hz。
HSYNC は x=656..751 の 96 pixel が Low、VSYNC は y=490..491 の二行が Low。
RGB と同期信号は同じ一クロックの遅延で出力し、可視領域外は RGB=0 にする。
`frame_tick` は一フレームにつき一クロックである。これは厳密な 25.175 MHz の
VGA clock ではなく、従来版の 25 MHz 設定を継承したもの。モニター互換性は実機確認が必要。

## 試験とプレビュー

`tb_versus_video` は次を自己検査する。

- 800×525 の一フレーム全体、HSYNC/VSYNC 幅、ブランキング、frame tick。
- 左右の固定ぷよ、灰色おじゃま、消去マーク、操作中の軸・子、NEXT の 13 pixel。
- 二人分の情報を可視フレーム中に変更しても、次の帰線期間まで表示が変わらないこと。
- 32 bit スコア最大値 4294967295、他方の 1234567890、予告 65535/31/8/30 の BCD。
- 0..255 の全連鎖表示 BCD、カウントダウンの数字、勝者/敗者文字。
- １人用 PLAY の全 420000 クロックについて、別に接続した旧 `PuyoVideo` と
  RGB・同期・frame tick が一致すること。

テストに `+PPM` を付けると、対戦の可視一フレームを `puyo_versus_video.ppm` に保存する。
これは手動設定した表示テスト盤面のレンダリングであり、実機モニターの写真や
対戦ソフトウェアの実プレイ動画ではない。PPM の改行は数値 LF (`%c`, 8'd10) で
出力し、Windows の VVP パス表記変換が文字列中の改行を壊さないようにしている。

シミュレーション・合成/配置配線・実機確認の状態は全体の検証報告を参照。
画面のテスト成功だけでキーボードの実機互換性やゲームルールの正しさは証明しない。
